# Juldyz: Интеллектуальная система поддержки отбора кандидатов в inVision U

**Трек:** AI inDrive (Decentrathon 5.0)
**Команда:** Revenant (Juldyz)

---

## Описание проблемы

inVision U ищет будущих лидеров и агентов изменений. Однако традиционный ручной скрининг заявок сталкивается с рядом проблем:

- **Потеря талантов:** Кандидаты с высоким потенциалом, но слабо развитым навыком «продажи себя» теряются на фоне формально идеальных заявок.
- **Риски ИИ-генерации:** Эссе, написанные с помощью ChatGPT, скрывают подлинный голос кандидата.
- **Масштабируемость:** С ростом потока заявок падает глубина и качество ручной оценки.

## Наше решение

**Juldyz** — это многомодальная data-driven система (AI Scoring Engine + Dashboard + Bot), которая помогает приёмной комиссии inVision U выявлять скрытый потенциал кандидатов на ранних стадиях.

Мы НЕ заменяем человека. Мы применяем принцип **Human-in-the-loop**, предоставляя комиссии обогащенные данные и прозрачный, объяснимый скоринг (Explainable AI).

### Ключевые возможности (Feature-лист)

1. **Многомодальный парсинг (Parser Service):** Автоматический сбор и стандартизация данных из разных источников (GitHub-профили, PDF резюме/CV) с использованием LLM для извлечения неструктурированного опыта.
2. **Умный скоринг (Scoring Service):** Оценка траектории роста и потенциала кандидата (Explainable AI — система всегда возвращает обоснование оценки).
3. **Telegram-бот (Bot Service):** Альтернативный, более "живой" и интерактивный канал первичного сбора данных о кандидате.
4. **Дашборд комиссии (Dashboard Service):** Удобный интерфейс для просмотра ранжированного шорт-листа с подсветкой ключевых сигналов потенциала.

## Архитектура решения

Решение построено на микросервисной архитектуре, что обеспечивает масштабируемость и независимую работу модулей:

```bash
juldyz/
├── core/              # Общие модули (БД, конфиги, логирование)
├── scripts/           # Скрипты локального запуска (bash)
├── services/
│   ├── bot/           # Telegram-интерфейс для сбора мотивации и данных в формате диалога
│   ├── dashboard/     # Web-интерфейс приёмной комиссии (рекомендации, шорт-листы)
│   ├── form/          # API обработки традиционных заявок
│   ├── parser/        # Обработка внешних источников (GitHub API, LLM PDF CV Parser)
│   └── scoring/       # Ранжирование кандидатов, генерация AI-объяснений (Explainability)
└── data/              # Локальное хранилище артефактов (links, files, processed JSONs)
```
